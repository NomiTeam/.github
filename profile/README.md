## 一起，把日子过成喜欢的样子

以 Minecraft 原版生存为底色，种一片田、钓一会儿鱼，做饭、建造，和朋友一起经营自己的小小日常。

- **当前版本**：Minecraft Java 版 **26.3**
- **入服方式**：按群公告获取我们的启动器并完成账号设置。使用我们的启动器启动游戏后，会自动进入服务器，无需手动添加。
- **玩法说明**：请查看游戏内菜单与帮助；最新客户端要求以群公告为准。
