## 关于团队

NomiTeam 围绕糯米小镇开发和维护网页与配套工具。我们的工作从网站上的信息呈现，延伸到账户管理、认证服务和启动入口，也包括为这些环节提供连接的验证插件。这里汇集相关代码与文档，方便了解项目之间的关系，也方便把问题和改进带到合适的仓库。

网站、账号和启动器各有自己的职责：官网承载糯米小镇的静态页面，Nomi Auth 提供账户管理与认证服务，启动器提供启动入口，QQ 验证插件则面向 Nomi Auth 提供配套验证。阅读或参与其中一项时，可以先从对应仓库的 README 入手，再按需了解相关项目。

## 开源与适配

组织内既有自有项目，也有来自上游的 Fork。我们根据实际需求开展适配，并尊重原项目的来源与作者。了解某个项目时，请结合其 README、许可文件与变更记录阅读；具体用途、兼容性和改动情况，以相应仓库记录为准。

更多项目可在 [组织仓库列表](https://github.com/orgs/NomiTeam/repositories) 中浏览。

## 交流与贡献

反馈、建议和代码或文档改进，都请围绕具体项目在对应仓库展开，便于保留上下文与后续讨论。

- **开始之前**：先查看仓库 README 和现有 Issue，了解说明与已有讨论。
- **反馈问题**：提供使用环境、复现步骤，以及预期行为和实际结果。
- **提出建议**：说明使用场景、遇到的困难，以及希望改善的体验。
- **提交 PR**：说明修改原因与验证方式；如有贡献指南，以仓库指南为准。

感谢每一份具体的反馈，也感谢上游作者与贡献者的工作。
